## [1.0.0] - 2026-10-07

### Added

- Six-step agent instructions with source tagging and a no-fabrication rule.
- Configuration files for intake sections, quality checks, and clarifying-question topics, each with a JSON Schema.
- Build script that validates configuration, renders paste-ready instructions, and packages a Glean agent specification.
- Setup guides for Glean, Copilot Studio, and custom applications.
- Worked example with fictional input and expected output.
- Evaluation method, scoring rubric, and CSV templates.
- Tests and continuous integration.
